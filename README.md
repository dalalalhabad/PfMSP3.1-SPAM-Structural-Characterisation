# PfMSP3.1 SPAM Structural Characterisation

Computational structural and functional characterisation of the
Plasmodium falciparum MSP3.1 SPAM domain.

This repository contains the computational workflow, processed results,
structural models, molecular dynamics analyses, docking analyses,
figures, tables, and reproducibility documentation associated with the
study.

## Project history

This work originated from a Master's research project conducted in 2020.
The study has subsequently been expanded for publication through
additional structural validation, including AlphaFold comparison,
cryo-EM density comparison, and further molecular dynamics analyses.

## Repository structure

- `01_original_2020_work` — original Master's research material
- `02_structural_modelling` — coiled-coil modelling and structural models
- `03_AlphaFold_validation` — AlphaFold structural comparison
- `04_cryoEM_validation` — cryo-EM density validation
- `05_MD_simulations` — molecular dynamics simulation setup and production
- `06_MD_analysis` — RMSD, RMSF, radius of gyration, PCA, clustering and related analyses
- `07_protein_docking` — protein-protein docking analyses
- `08_complex_MD` — molecular dynamics simulations of selected docked complexes
- `09_figures` — manuscript figures
- `10_tables` — processed numerical results and manuscript tables
- `11_supplementary` — supplementary analyses and figures
- `reproducibility` — commands, software versions, parameters and workflow documentation
- `manuscript` — manuscript-related files

## Status

This repository is currently under development and corresponds to
unpublished research. It will remain private until publication or until
the authors decide to release the associated materials.

# Original 2020 work

This directory retains source material from the original 2020 Master's research that is most appropriately preserved at the project-entry level.

## Sequence analysis

`sequence_analysis/BS0AEKNU014-Alignment.txt`

Historical BLASTP alignment output associated with the 139-residue PfMSP3.1 SPAM sequence used in the original structural-modelling study.

## Organisation of the remaining historical work

The original 2020 research files have been reorganised by scientific workflow rather than duplicated in this directory:

- Structural modelling: `02_structural_modelling/`
- Original SPAM molecular dynamics: `05_MD_simulations/`
- MD analysis and salt-bridge results: `06_MD_analysis/original_2020/`
- Protein-protein docking and BSA/ZRANK analysis: `07_protein_docking/historical_2020/`
- Protein-complex MD simulations: `08_complex_MD/historical_2020/`
- Thesis figures: `09_figures/historical_2020/`
- Thesis result tables: `10_tables/historical_2020/`

This organisation preserves the historical files while presenting the workflow in a form that is easier to follow and reproduce.
